# 🏠 Rent Apartment App

Rent Apartment is a modern mobile application designed to simplify the apartment rental process by connecting tenants and lessors through a single, user-friendly platform.

The app provides a complete rental management experience, covering everything from browsing apartments to booking, communication, and secure transaction handling.

---

## 🖥 Admin Dashboard

- Full control over users and accounts  
- Account verification and status management  
- Review and manage wallet requests (add & withdraw)  
- Secure and well-organized administrative system  

---

## 🏢 Lessor Features

- Add and manage apartments with images and full details  
- Receive and manage booking requests  
- Accept or reject reservations easily  
- Real-time notifications for new booking requests  
- Manage current and past reservations  
- Communicate with tenants via in-app chat  
- Request wallet withdrawals  

---

## 🏠 Tenant Features

- Browse available apartments easily  
- Advanced filtering system to find the perfect home  
- View full apartment details with images  
- Select booking dates smoothly  
- Send booking requests directly from the app  
- Real-time notifications  
- Add apartments to favorites  
- Rate and review apartments  
- Chat directly with the lessor  
- Manage personal reservations  

---

## ⚙️ Additional Features

- Personal profile for each user  
- Multi-language support  
- Dark mode  
- Clean and intuitive user interface  
- Secure and reliable experience
